# 洞府系统设计

## 1. 设计目标
洞府是玩家的「私人领地」，承担修炼加速、资源产出、闭关避险、设施经营等多重功能，形成从「租赁」到「自建」的成长线。

## 2. 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 灵石（租金） | 修炼速度加成、闭关场所 | 租期到期失效；长期租金压力 |
| 闭关时间 | 额外修为 | 跳过常规事件与社交 |
| 材料与灵石（设施建设） | 持续资源产出 | 前期投入大；设施可能被破坏 |
| 护山大阵维护费 | 洞府安全 | 未维护时妖兽/敌对势力可入侵 |
| 灵脉争夺 | 更高品质洞府 | 引发战斗或势力敌对 |

## 3. 洞府类型

| 类型 | 获取方式 | 特点 | 适合阶段 |
|------|----------|------|----------|
| 城中洞府 | 租赁 | 安全、加成固定、无维护 | 早期 |
| 宗门洞府 | 宗门职位奖励 | 共享灵脉、靠近宗门资源 | 中期 |
| 野外洞府 | 占领灵脉 | 可升级、可自定义设施、可被攻击 | 中晚期 |
| 秘境洞府 | 完成特定剧情/任务 | 特殊加成、唯一 | 后期 |

## 5. 洞府事件

| 事件 | 触发条件 | 结果 |
|------|----------|------|
| 灵气潮汐 | 每月概率 | 某种灵气浓度 ±30%，持续数月 |
| 妖兽袭扰 | 无护阵或护阵失效 | 战斗；胜利得材料，失败设施损坏 |
| 访客求药 | 有药园/炼丹室 | 可选择交易、拒绝或结仇 |
| 灵脉枯竭 | 野外洞府长期开采 | 加成下降，需迁移或修养 |
| 洞府升级 | 投入材料与灵石 | 解锁新设施位、提升基础加成 |

## 6. 闭关修炼

### 6.1 规则
- 玩家选择洞府与闭关月数（1~12 个月）。
- 闭关期间每月获得额外修为，并消耗对应洞府租期。
- 闭关期间跳过常规事件与社交，但洞府事件仍可触发。

### 6.2 收益公式
```
每月修为 = 基础修为 × (1 + 洞府闭关加成) × (1 + 闭关月数累计加成)
总修为 = Σ 每月修为
```

### 6.3 风险
- 闭关中被入侵且失败：闭关中断，修为损失，可能重伤。
- 租期耗尽：闭关自动结束，剩余月份按普通修炼结算。
