# 核心系统设计

## 1. 修炼与境界系统

### 1.1 设计目标
让玩家通过月度修炼积累修为，在关键时刻尝试突破，体验「水到渠成」与「逆天改命」的张力。

### 1.2 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 时间（每月修炼行动） | 修为增长 | 无直接风险，但错过事件与社交 |
| 灵石（购买丹药） | 修炼速度加成 | 经济压力，可能导致买不起装备 |
| 丹药（筑基丹等） | 突破成功率提升 | 丹药稀缺，用错境界无效 |
| 心境值 | 突破时心魔劫抵抗 | 心境过低触发心魔，失败重伤 |
| 寿元 | 无直接输出 | 寿元耗尽则强制转世 |

### 1.3 关键规则
- 每个小境界有修为上限，满值后可尝试突破。
- 大境界突破触发天劫/心魔事件，成功率受根骨、丹药、心法影响。
- 失败惩罚：小境界突破失败修为倒退；大境界突破失败可能境界跌落或死亡。

## 2. 灵根与流派系统

### 2.1 设计目标
通过灵根组合与流派选择，构建差异化 Build，并让每次重玩都有不同体验。

### 2.2 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 初始灵根 | 可修炼属性、克制关系 | 单灵根修炼快但易被克制；多灵根全面但经验需求高 |
| 洗髓丹 / 奇遇 | 觉醒新灵根 | 每多一个灵根，所需修为提升 |
| 流派选择（法修/剑修等） | 专属资源与技能修正 | 切换流派需遗忘技能、清空资源 |
| 灵根纯度 | 对应属性技能伤害 | 纯度低时属性技能收益不足 |

### 2.3 关键规则
- 五行相克：金克木、木克土、土克水、水克火、火克金。
- 变异克制：雷克金、冰克火、风克木。
- 流派限制：剑修必须持剑，体修依赖怒气，邪修邪气过高触发正道追杀。

## 3. 战斗系统

### 3.1 设计目标
提供策略性回合制战斗，强调属性克制、技能搭配与资源管理。

### 3.2 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 技能（真气/怒气/剑意） | 伤害 / 控制 / 治疗 | 用错资源导致下回合乏力 |
| 装备 | 攻防血属性 | 装备维修/替换成本 |
| 丹药（战斗中可用） | 临时回血/解控 | 丹药消耗，战后需补充 |
| 五行判断 | 克制增伤 1.5x，被克减伤 0.7x | 敌人属性未知时可能吃亏 |
| 控制效果 | 封印/眩晕/减速 | 敌人也可能控制玩家 |

### 3.3 关键规则
- 每回合玩家选择技能或道具，敌人按 AI 行动。
- 控制技能有成功率，受境界与技能等级影响。
- 战斗失败：低境界可逃跑/复活，高境界可能重伤或死亡。

## 4. 心法与神通系统

### 4.1 设计目标
作为中后期 Build 深度来源，让同一境界玩家因心法神通不同而有截然不同的战斗风格。

### 4.2 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 秘籍 / 论道 / 宗门贡献 | 学习新心法/神通 | 心法冲突：同时装备过多导致走火入魔概率上升 |
| 悟道点 | 神通升级 / 解锁法则 | 悟道点有限，选错方向难以回头 |
| 修炼时间 | 心法熟练度 | 心法未熟练时效果打折 |

### 4.3 关键规则
- 心法有装备上限，高品质心法占用更多「神识」。
- 神通需要特定灵根或流派解锁。
- 法则融合：高境界可将两种属性神通融合为复合神通。

## 5. 道心与心魔系统

### 5.1 设计目标
在修仙路上加入心理维度，让玩家在追求力量的同时维持道心稳定。

### 5.2 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 论道胜利 / 悟道 | 道心值提升 | 无 |
| 杀戮无辜 / 邪修行为 | 心魔值上升 | 突破时心魔劫难度增加 |
| 重大失败 / 亲友死亡 | 道心值下降 | 可能触发心魔入侵事件 |
| 心魔值过高 | 战斗中有概率被心魔控制 | 随机攻击自己或队友 |

### 5.3 关键规则
- 道心 0~100，50 为平常心。
- 心魔值达到阈值后，突破必触发心魔劫。
- 心魔劫为特殊战斗，胜利则道心大增，失败则境界受损。
