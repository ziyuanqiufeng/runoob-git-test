# 经济平衡设计

## 1. 设计目标
构建一个有多元收入来源和明确消耗出口的经济系统，让玩家在早期感到拮据、中期自给自足、后期有经营空间。

## 2. 输入-输出-风险表（经济整体）

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 时间（任务/探索/经营） | 灵石、材料、装备 | 错过修炼或事件 |
| 灵石投资（洞府/设施/店铺） | 持续被动收入 | 前期资金紧张；经营失败损失本金 |
| 市场交易（低买高卖） | 价差利润 | 价格波动、囤货滞销 |
| 社交投入（送礼/请客） | 好感度、任务机会 | 资源消耗，可能打水漂 |
| 战斗/劫掠 | 战利品 | 生命危险、正道声望下降 |

## 3. 收入来源

| 来源 | 阶段 | 稳定性 | 备注 |
|------|------|--------|------|
| 任务奖励 | 早期 | 稳定 | 城市任务、宗门任务、悬赏 |
| 洞府产出 | 中期 | 稳定 | 药园、炼丹室等设施 |
| 摆摊 | 中期 | 中等 | 受城池声望与商品价值影响 |
| 拍卖行 | 中晚期 | 波动大 | 稀有物品价高者得 |
| 宗门俸禄 | 中期 | 稳定 | 与职位挂钩 |
| 城主收益 | 晚期 | 稳定 | 当选后获得税收/政策收益 |
| 探索/BOSS | 全期 | 波动大 | 高风险高回报 |
| 劫掠/走私 | 邪修路线 | 高波动 | 正道声望暴跌 |

## 4. 消耗出口

| 消耗项 | 阶段 | 作用 |
|--------|------|------|
| 洞府租金/维护 | 全期 | 维持修炼加成与产出 |
| 丹药 | 全期 | 突破、战斗、疗伤 |
| 装备强化/修复 | 中期 | 提升战斗能力 |
| 技能学习 | 中期 | 解锁新心法/神通 |
| 社交送礼 | 全期 | 提升 NPC 好感 |
| 传送阵 | 中晚期 | 快速移动 |
| 竞选/政策 | 晚期 | 政治投入 |
| 设施升级 | 中晚期 | 提升洞府产出 |

## 5. 物价波动机制

### 5.1 影响因素
- **城池类型**：玄水城水系材料便宜，赤焰城火系材料便宜。
- **城池政策**：减税令降低交易税，商会扶持加快出售速度。
- **世界事件**：魔道入侵导致丹药涨价，灵气复苏降低修炼丹药需求。
- **玩家行为**：大量抛售同一种材料会导致该材料价格下跌。

### 5.2 动态价格公式
```
实际价格 = 基础价格 × 城池系数 × 事件系数 × 供需系数 × 玩家折扣
```

## 6. 经济健康指标

- 早期玩家月收入应略低于必要支出，迫使其做选择。
- 中期玩家通过洞府/任务可实现收支平衡并有结余。
- 晚期玩家应有多余资本投入政治、拍卖、设施升级。

## 7. 风险控制

- **通货膨胀**：避免后期灵石过度溢出，通过设施维护、高级丹药、政治投入持续回收。
- **通货紧缩**：确保任务奖励和基础产出足够支撑早期生存。
- **套利滥用**：限制同物品跨城无限倒卖（加入运输成本与时间成本）。
