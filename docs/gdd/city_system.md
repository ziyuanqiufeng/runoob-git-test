# 城池系统设计

## 1. 设计目标
将每座城池从「商店集合」升级为玩家月度决策中枢，通过建筑选择、声望经营、城主政治产生持续的目标感。

## 2. 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 时间（访问建筑） | 任务、交易、情报、修炼场所 | 每月主行动有限，访问 A 就错过 B |
| 灵石 | 商品、丹药、情报、租金 | 经济压力 |
| 城池声望 | 解锁高级商品、竞选资格、税率优惠 | 声望下降导致被驱逐或涨价 |
| 支持城主候选人 | 城主当选后获得政策红利 | 支持失败则被新政权打压 |
| 参与城池事件 | 声望、奖励、稀有物品 | 失败可能损失声望或生命 |

## 3. 建筑功能矩阵

| 建筑 | 核心玩法 | 决策点 |
|------|----------|--------|
| 城主府 | 城市任务、竞选、治理 | 支持谁？颁布什么政策？ |
| 客栈 | 休息、打听传闻、触发奇遇 | 花多少钱买情报？相信哪条？ |
| 坊市 | 交易、摆摊、拍卖 | 低买高卖、囤货风险 |
| 演武场 | 擂台挑战、排名奖励 | 挑战谁？连胜风险？ |
| 炼丹阁 | 购买/炼制丹药 | 自采 vs 购买？ |
| 洞府 | 租赁、闭关 | 短期冲刺 vs 长期持有？ |
| 宗门办事处 | 宗门任务、外交 | 为宗门效力 vs 谋取私利？ |

## 4. 城池氛围差异

| 城池 | 特色 | 机会 | 风险 |
|------|------|------|------|
| 玄水城 | 水系资源便宜、水灵气浓郁 | 水修修炼快、疗伤丹药多 | 夜间妖兽事件频发 |
| 赤焰城 | 火系/丹修友好、地火洞府 | 炼丹成功率高、火伤加成 | 火山喷发随机破坏 |
| 万妖城 | 御兽材料丰富、妖核交易 | 灵兽成长快、妖兽材料便宜 | 正道声望下降、治安差 |
| 云岚城 | 高端洞府、论道/拍卖活跃 | 高阶心法/神通易获取 | 租金昂贵、竞争激烈 |
| 落霞城 | 均衡型新手城 | 资源全面、任务简单 | 高级资源少 |
| 忘川镇 | 魂修/阴气主题 | 魂修修炼加成、渡魂灯特产 | 阳气受损、健康下降 |

## 5. 城主竞选与政策

### 5.1 竞选流程
1. 玩家达到声望门槛后可报名参选。
2. 消耗灵石与声望进行拉票。
3. 月度推进时根据支持率决定当选者。
4. 当选后任期 N 个月，可颁布有限数量的政策。

### 5.2 政策类型

| 政策 | 效果 | 代价 |
|------|------|------|
| 减税令 | 城中交易税降低 | 城主府收入减少 |
| 灵脉滋养 | 洞府修炼加成提升 | 每月消耗灵石维护 |
| 戒严令 | 妖兽攻城频率降低 | 玩家自由度受限（部分 NPC 消失） |
| 商会扶持 | 摆摊出售速度加快 | 拍卖行刷新品质下降 |
| 招贤令 | 高阶 NPC 出现概率提升 | 治安事件增加 |

### 5.3 失败风险
- 落选：投入的灵石/声望不返还，可能遭当选者派系打压。
- 任期结束：政策自动失效，需重新竞选。
