# 增强吸引力的 Feature Pitch

本文档聚焦「还能添加什么设计让游戏更吸引人」，从叙事、策略、收集、社交、随机性五个维度提出可落地的扩展方向，每条都包含设计目标、输入-输出-风险表、吸引力来源与实现要点。

---

## 1. 转世轮回与多周目继承

### 设计目标
让玩家的一次通关不是终点，而是下一世的起点，形成「越玩越强、剧情越深」的长线动力。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 死亡或飞升 | 转世机会 | 转世后境界归零 |
| 前世成就（境界、名望、关系） | 可继承的天赋/物品/关系 | 继承有限，避免破坏早期体验 |
| 因果业力 | 转世奇遇或诅咒 | 业力过高可能转世为废灵根 |

### 吸引力来源
- **多周目新鲜感**：每次转世保留部分元素，但开局仍不同。
- **长期目标**：玩家会为了「完美转世」而努力积累。
- **叙事回收**：前世仇家、前世道侣可能在下一世再相遇。

### 实现要点
- 新增 `reincarnation_count`、`karma`、`past_life_talents` 等 Player 字段（部分已预留）。
- 结局时计算可继承项，以选择界面呈现。
- 高业力玩家转世时触发负面事件，低业力可触发「天骄转世」加成。

## 2. 弟子培养与宗门传承

### 设计目标
让玩家从「被宗门管理」成长为「管理宗门的人」，体验开宗立派、传承道统的成就感。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 招收弟子（消耗声望/资源） | 弟子成长后贡献资源、参战 | 弟子可能背叛、陨落 |
| 传授心法/功法 | 弟子实力提升 | 核心功法外泄给敌对势力 |
| 指派弟子任务 | 资源、声望、情报 | 任务失败弟子死亡 |
| 立掌门继承人 | 玩家转世或飞升后宗门延续 | 继承人资质影响宗门未来 |

### 吸引力来源
- **养成反馈**：把 NPC 从小境界培养成大能。
- **势力延续**：玩家飞升后仍能看到自己创建的宗门继续存在。
- **情感绑定**：弟子有自己的名字、事件、结局。

### 实现要点
- 扩展 `disciples` 数据结构，加入 `growth`、`loyalty`、`task`、`death_risk`。
- 弟子每月自动修炼，玩家可指派任务、赐予物品。
- 宗门大比、外敌入侵时弟子可参战。

## 3. Roguelike 秘境探险

### 设计目标
提供高随机性、可重复游玩的副本体验，每次进入都是新的挑战与奖励。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 秘境钥匙/时间 | 进入随机生成关卡 | 失败后损失钥匙，部分收益清零 |
| 路线选择 | 遭遇战斗、宝箱、事件、BOSS | 选错路线可能连续战斗 |
| 临时 Buff/Debuff | 通关后带出部分奖励 | 部分 Buff 只在秘境内生效 |
| 隐藏条件 | 解锁隐藏层、稀有 BOSS | 触发条件苛刻 |

### 吸引力来源
- **高复玩性**：地图、敌人、奖励随机组合。
- **决策密度**：每一步都要权衡风险与收益。
- **稀有奖励**：只在秘境中掉落的特殊心法、神通、材料。

### 实现要点
- 设计秘境生成器：房间类型（战斗/事件/商店/休息/BOSS）+ 敌人组合 + 奖励表。
- 配置 `secret_realms.json` 定义主题（火域、冰原、雷池等）。
- 每次进入生成临时存档，失败后回滚。

## 4. 奇遇链：分支叙事事件

### 设计目标
用高文本量的选择分支事件替代纯数值事件，让玩家感觉「这个世界在回应我的选择」。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 探索/移动触发 | 进入奇遇事件 | 错误选择可能导致重伤、结仇 |
| 多个选项 | 不同奖励或后续事件 | 部分选项需要特定灵根/流派 |
| 连续选择 | 形成个人专属故事线 | 选择不可逆 |

### 吸引力来源
- **叙事沉浸**：类似《太吾绘卷》《鬼谷八荒》的奇遇体验。
- **高度个人化**：不同玩家会经历完全不同的故事。
- **意外惊喜**：隐藏结局、稀有奖励、特殊 NPC。

### 实现要点
- 设计 `encounter_chains.json`，支持多节点、条件分支、延迟触发。
- 使用 `dialogue_flags` 记录玩家选择。
- UI 使用卷轴式文本 + 选项按钮，增强古风感。

## 5. 灵兽羁绊与进化

### 设计目标
让灵兽不只是战斗数值，而是有成长、情绪、进化的伙伴。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 捕获灵兽 | 获得战斗伙伴 | 高阶灵兽可能反噬 |
| 喂养/训练 | 成长、忠诚度提升 | 食物/材料消耗 |
| 特殊材料/丹药 | 灵兽进化/变异 | 进化失败可能退化 |
| 共同战斗 | 灵兽技能熟练度 | 灵兽死亡需复活道具 |

### 吸引力来源
- **收集欲**：不同属性、形态、稀有度的灵兽。
- **陪伴感**：灵兽会在城市中跟随、在战斗中互动。
- **Build 扩展**：灵兽技能与玩家技能形成组合技。

### 实现要点
- 扩展 `beasts` 数据结构，加入 `growth_stage`、`loyalty`、`mood`、`evolution_path`。
- 灵兽进化需要满足等级 + 材料 + 亲密度条件。
- 战斗中灵兽作为独立单位行动。

## 6. 炼器、附魔与装备词缀

### 设计目标
让装备系统从「换更好装备」升级为「打造专属神兵」，增加 Build 深度。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 基础装备 + 材料 | 强化等级提升 | 强化失败装备降级或损毁 |
| 稀有材料 | 附加随机词缀 | 词缀随机，可能不想要的属性 |
| 器灵/魂魄 | 装备觉醒特殊效果 | 器灵有忠诚度，可能噬主 |
| 重铸道具 | 重置词缀 | 材料稀缺 |

### 吸引力来源
- **刷装备动力**：追求极品词缀组合。
- **流派定制**：剑修堆暴击，体修堆生命，法修堆真气。
- **视觉反馈**：装备强化后发光、改变外观。

### 实现要点
- 扩展 Item 结构，支持 `enhancement_level`、`affixes`、`spirit`。
- 炼器台 UI 展示强化成功率、消耗材料、预览属性。
- 高强化等级引入失败惩罚，制造紧张感。

## 7. 动态世界阵营大战

### 设计目标
让整个世界不只是背景，而是持续演变的势力棋盘，玩家的选择真正改变世界格局。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 玩家阵营选择 | 解锁对应势力任务 | 敌对阵营追杀 |
| 参与战争事件 | 改变城池/宗门归属 | 失败方声望暴跌 |
| 暗中破坏/外交 | 削弱敌方、结盟 | 被发现后关系恶化 |
| 关键战役胜利 | 世界进入新阶段 | 新阶段带来新威胁 |

### 吸引力来源
- **史诗感**：玩家感觉自己参与了改变世界的大事。
- **重玩价值**：选择不同阵营体验完全不同的剧情。
- **动态世界**：同一座城市可能由正/魔/不同宗门控制。

### 实现要点
- 为世界势力设计 `faction_power` 与 `territory_control`。
- 战争事件通过多阶段任务推进，玩家可参与关键战役。
- 城池建筑与 NPC 随控制势力变化。

## 8. 名望、称号与排行榜

### 设计目标
让玩家追求「被世界记住」，而不仅仅是数值变强。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 成就/事件/排名 | 名望值 | 名望过高引来挑战者 |
| 名望等级 | 解锁称号、特殊待遇 | 称号可能带来负面阵营倾向 |
| 排行榜竞争 | 专属奖励 | 被其他 NPC 视为目标 |

### 吸引力来源
- **身份认同**：「剑道第一天骄」「魔道巨擘」等称号。
- **目标感**：明确的排行榜与成就列表。
- **社交炫耀**：在 NPC 对话中被称呼称号。

### 实现要点
- 新增 `fame` 与 `title` 系统，称号附带小幅度属性或效果。
- NPC 根据玩家称号改变对话与态度。
- 排行榜覆盖境界、财富、宗门贡献、击杀等维度。

## 9. 天气与灵气潮汐系统

### 设计目标
让时间与地点成为策略变量，玩家需要「择时择地」修炼与战斗。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 月份/季节 | 灵气潮汐变化 | 错过最佳时机效率降低 |
| 天气 | 特定属性加成/削弱 | 雷雨天雷修更强，火修更弱 |
| 天象事件 | 全地图效果 | 可能触发特殊事件或灾难 |

### 吸引力来源
- **策略深度**：玩家会主动规划修炼与探索时间。
- **世界真实感**：世界随时间变化。
- **仪式感**：「月圆之夜突破」「雷劫之日渡劫」等情境。

### 实现要点
- 世界层维护 `weather`、`season`、`spirit_tide` 状态。
- UI 中增加天象面板，提示当前加成。
- 特殊天象与事件、突破、渡劫联动。

## 10. Mod 与自定义内容支持

### 设计目标
让社区能持续为游戏生产内容，延长游戏生命周期。

### 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 玩家/作者制作的 Mod | 新事件、新角色、新地图 | 低质量 Mod 影响体验 |
| Mod 加载器 | 游戏内容扩展 | 版本更新可能导致 Mod 失效 |
| 创意工坊/本地目录 | 分享与下载 | 需要维护兼容性 |

### 吸引力来源
- **无限内容**：玩家社区持续产出。
- **个性化**：玩家可以按自己喜好改造游戏。
- **长尾传播**：优质 Mod 带来新玩家。

### 实现要点
- 所有配置使用 JSON，便于 Mod 覆盖。
- 设计 Mod 目录结构：`mods/<mod_name>/config/`、`mods/<mod_name>/assets/`。
- 提供 Mod 加载顺序与冲突检测工具。

## 优先级建议

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P1 | 奇遇链分支叙事 | 投入文本即可显著提升沉浸感，技术门槛低 |
| P1 | 灵兽羁绊与进化 | 与现有御兽系统衔接，扩展战斗 Build |
| P1 | 炼器附魔词缀 | 与现有装备系统衔接，提升刷装动力 |
| P2 | 转世轮回继承 | 增加多周目动力，但需要稳定核心体验后实现 |
| P2 | Roguelike 秘境 | 高复玩性，但需要独立关卡生成与平衡 |
| P2 | 动态阵营大战 | 需要宗门/城池系统成熟后才有意义 |
| P3 | 弟子培养传承 | 适合晚期内容，与转世系统配合更佳 |
| P3 | Mod 支持 | 适合游戏基本完成后开放，长期收益大 |

## 最小可玩组合（MVP）

如果只想用最小成本验证吸引力，推荐组合：
1. **奇遇链**：新增 10~20 条短奇遇，覆盖练气到筑基阶段。
2. **炼器词缀**：为现有装备增加 3~5 种随机词缀。
3. **天气灵气潮汐**：每月随机一种灵气潮汐，影响修炼与战斗。

这三项都能在现有架构上快速实现，并显著提升玩家感知到的「世界感」与「Build 深度」。
