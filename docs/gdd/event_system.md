# 事件系统设计

## 1. 设计目标
通过多层次事件系统，让世界保持动态变化，并为玩家提供持续的短期目标、意外惊喜和叙事记忆。

## 2. 输入-输出-风险表

| 输入 | 输出 | 风险 / 代价 |
|------|------|-------------|
| 探索/移动行为 | 随机遭遇、遗迹、BOSS | 可能遭遇强敌或陷阱 |
| 月度 tick | 城池/宗门/世界事件 | 错过参与机会或被迫应对危机 |
| 玩家境界/声望/阵营 | 触发符合条件的事件 | 高声望引来挑战，邪修引来追杀 |
| NPC 关系 | 个人剧情事件 | 选择错误导致关系恶化 |
| 历史年表 | 叙事回顾与成就依据 | 无直接风险，但影响多周目继承 |

## 3. 事件分层

### 3.1 随机遭遇事件
- **触发**：玩家探索、赶路、访问野外地点时按概率触发。
- **例子**：路遇劫修、发现上古洞府、救助受伤散修、撞见妖兽觅食。
- **设计要点**：低风险高频率，提供小资源或关系变化。

### 3.2 城池事件
- **触发**：城池月度 tick，受城池类型、政策、玩家声望影响。
- **例子**：
  - 妖兽攻城：多波战斗，胜利提升声望与奖励。
  - 商队抵达：限时折扣商品。
  - 城主换届：支持候选人的最后窗口。
  - 灵气异动：特定属性修士临时加成。

### 3.3 宗门事件
- **触发**：宗门月度 tick，受宗门等级、外交、玩家职位影响。
- **例子**：
  - 宗门大比：内部排名赛，奖励贡献与秘籍。
  - 外敌入侵：宗门战，参与获得声望与战利品。
  - 长老陨落：职位空缺，玩家可竞争晋升。
  - 祖师堂开启：参悟传承机会。

### 3.4 世界事件
- **触发**：全局月度 tick，影响所有玩家/NPC/城池。
- **例子**：
  - 魔道入侵：正魔大战，玩家选择阵营。
  - 天材地宝出世：全地图争夺稀有资源。
  - 灵气复苏：全区域修炼速度提升。
  - 大劫将至：渡劫难度增加，特殊任务开启。

### 3.5 个人剧情事件
- **触发**：基于玩家关系、境界、选择。
- **例子**：
  - 师父召见：传授心法或交付任务。
  - 道侣危机：需要救援或做出选择。
  - 仇敌复仇：被追杀或主动出击。
  - 心魔入侵：进入心魔战斗。

## 5. 连锁事件

- 玩家在某事件中选择 A，可能在数月后触发 A 的后续事件。
- 例子：救助散修 → 散修上门报恩 → 散修被仇家追杀 → 玩家卷入恩怨链。
- 通过 `dialogue_flags` 或事件状态机记录选择，形成个人叙事线。

## 6. 历史年表

- 每个世界事件、玩家重大选择、突破、击杀、关系变化都写入年表。
- 年表用于：
  - 结局结算（「正道楷模」「魔道巨擘」「逍遥散人」等）。
  - 多周目继承（转世时保留部分天赋/关系/名望）。
  - 成就解锁。
