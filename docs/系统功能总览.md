> 汇总时间：2026-09-16（数字更新于 10-09：终局链/轮回叙事/AI 角色引擎后）

## 二、核心玩法

### 1. 修炼与境界
- 22 级境界渐进解锁玩法（练气 9 层 → 筑基/金丹各 4 阶 → 元婴 → 化神/炼虚终局链）；灵根（五行 + 雷冰风变异/融合）决定属性与神通。
- **天门试炼**：炼虚圆满冲击飞升的三阶段试炼（问心→渡雷→天门一跃），心魔/天道红线直接坏结局，普通失败兵解重创可再战；飞升丹（丹道可炼）提升成功率 30%。
- 突破大境界需**渡劫**（雷劫 + 心魔考验），失败可能走火入魔。
- 元婴期解锁**神识扫描**（洞察妖兽弱点）与**替死机制**（一次离体挡死）。

### 2. 游历与世界
- 28 地点各有性格：城池市井（人际/商贩高发）、宗门清净（修炼/走火高发）、野外凶险（资源/战斗高发）。
- 53 个随机事件按地点权重抽取（奇遇/危机/人际/资源/特殊五类）；**3 个终局专属事件**带境界门槛（化神 19+/炼虚 21+）；**7 个周目模式专属事件**（魔道围剿/魔道交易/凡人之志/轮回宿慧/天道常视/躯壳排异/故主寻亲）按 game_mode 过滤，standard 玩家不可见。
- 世界 BOSS、世界事件、天气/灵气潮汐驱动长线节奏。

### 3. 战斗系统
- 回合制 + 五行相克 + 控制效果（盾/封/晕/反伤）。
- 151 技能带熟练度成长（`mastery_effects`）；敌人有境界缩放、特殊技能、召唤机制。
- **战斗意图预告**：玩家行动前显示敌人本回合决策（普攻/技能名+预计伤害/疗伤/加持/遁走），预判缓存不二次随机。

### 3.1 试炼塔（连续波次挑战）
- 15 层四档敌人梯度（enemies.json 真实数据）；每层灵石递增、每 5 层物品、通关大奖。
- 每层胜利后三选一补给（疗伤丹/聚气丹/灵石/灵草，复用物品系统零属性污染）。
- **撤退全额结算 / 战败折半**；最高层纪录 `trial_tower_best` 跨世保留。
- 入口：行动面板「试炼塔」；战斗复用现有系统（`pending_trial` 钩子推进/结算）。

### 4. 经营与势力
- 洞府租赁/闭关、摆摊、拍卖、坊市；领地建设/产出/防御。
- 10 宗门（外门→掌门晋升）、城主竞选与政策、家族系统（联姻/继承）。

### 4.1 NPC 个人支线（101 位全覆盖）

- 每位 NPC 一条专属委托，按 `npc_id` CRC32 **确定性生成**（物品/数量/文案/敌人恒定，人设稳定）。
- 三型分派：**寻物**（交付物品）/ **护法**（替 TA 挡下妖邪）/ **复仇**（替 TA 出气）——战斗型接取即出发。
- 奖励：灵石 + 好感 + 共同记忆 + 年表；战斗失败委托保留可再战。
- **好感门槛**：好感 < -10 者不愿托付（与"魔道独行·正道皆敌"自然联动——正道修士不会请魔头办事）。

### 5. 长线机制
- 心魔/心境/道心/信念四维状态；天道注视与降罚。
- 红尘羁绊；百家争鸣。
- **轮回叙事层（多周目核心）**：
  - 结局后「转世重修」→ 继承选择弹窗（继承点 = 境界分+名望分+业力修正；可选灵根保留/天赋/属性/携带物品/关系保留/业力洗涤），遗物链跨世累积；
  - **前世羁绊**：道侣（按亲密度）或好感最高 NPC 跨世记为 past_bond；
  - **转世重逢 NPC**：新周目自动注入前世羁绊者转世（似曾相识文案、道侣可双修、`past_life_bond` 供 AI 剧情引用），宿慧开局叙事 + 年表记「第 N 世启程」；
  - 二周目可与转世道侣再结缘——前世与今生记忆在同一位 NPC 身上延续。
- **8 结局**：飞升成仙 / 魔道登天 / 大道独行 / 走火入魔 / 天道降罚 / 兵解重修 / 红尘归隐 / 凡尘谢幕。
- **修行图鉴（跨世收集）**：结局图鉴（8 个）/ 人物图鉴（101 NPC，已相识高亮）/ 试炼塔纪录三合一；`meta_collection` 转世合并继承（越玩越厚）。入口：帮助菜单。
- **节日灯会**：节日限定的灯谜小玩法（5 题题库随机 3 题，答对 ×30 灵石，全对心境 +5）；非节日不可入。

### 6. 主线剧情
- 章节制推进，按境界/宗门/结局条件解锁，全部完成后走完“问道长生之路”。

## 三、AI 能力（Agnes 系，同一 key）

| 模型 | 用途 | 状态 |
|---|---|---|
| `agnes-3.0-flash`（LLM） | 游历动态剧情：按地点+心境生成专属古风文案 | 已接入 `api.agnes-ai.cn`，实测 1~7.5s/次 |
| `agnes-image-2.1-flash`（文生图） | AI 立绘生成 + 捏脸部件 | 已接入，503 自动重试 |

**两段式 AI 剧情**：离线文案秒渲染（界面零阻塞）→ 后台线程生成 AI 文案 → 以「✨ AI 剧情」追加日志。失败自动降级离线模板。

**AI 角色引擎（三步，2026-09-30 收官）**：
- **NPC 记忆**：结道侣/双修/论道/收徒/传艺等动作自动写入共同经历（每 NPC 最近 5 条），NPC 对话窗显示「共同回忆」时间线；
- **主动事件**：NPC 按关系状态主动发起交互——道侣赠丹（亲密度≥40）、弟子聆教、宿敌寻衅（月度判定，频率/门槛/惩罚配置化 `config/social_events.json`）；
- **AI 喂料**：游历剧情的提示词自动携带「与故人的共同往事」（最近 3 条记忆），AI 笔下角色带着玩家的真实历史。

**天门试炼演出**：三阶段结算面板（✓/△/✗/★ 徽标 + 成功率/资源消耗明细 + 白日飞升/折戟天门/试炼终局三态总结）。

**AI 捏脸（双路线）**：
- AI 提示词：5 维特征（脸型/眼神/气质/发型/服饰）→ 整张水墨立绘（约 1 分钟）。
- 拼装：25 个 AI 水墨部件 × 3 肤色，PIL 实时合成，参数可复现，🎲 随机一键。

**玩家自助**：
- 功能开关（15 项）设置面板可视化切换。
- 「测试 AI 连接」一键诊断 key/网络/LLM+图模型。
- 游戏中头像右键随时**重捏脸**。

## 四、存档与数据安全

- 多槽位 + **原子写入**（tmp + os.replace，断电不损档）。
- **滚动备份**：`saves/backups/` 保留 5 份。
- **版本迁移**：旧存档自动 `_migrate`。
- **导出/导入**：zip 分享包（含自定义立绘），导入自动修复立绘路径。
- API key 等敏感配置已 gitignore，不入 GitHub。

## 五、质量保障

- **1327 测试用例**（单元/集成/UI offscreen），含**轮回全链路集成测试**（结缘→终局→试炼→飞升→转世→新周目→再结缘，8 功能单链确定性回归）。
- 配置驱动：数值/事件/开关尽量 JSON 化，调平衡不改代码。
- 月度结算插座（`register_monthly_tick`）+ 单系统异常隔离。
- 性能基准：单月 0.08ms / 存档 8ms / 事件抽取 14.2µs（`tools/bench_tick.py`）。
- 曲线复测工具：`tools/curve_check.py`（纯闭关口径，实测元婴 143 年→炼虚圆满 502 年）、`tools/roam_check.py`（游历流对照口径）。
