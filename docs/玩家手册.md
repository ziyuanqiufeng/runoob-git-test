# 《问道长生》玩家手册

> 版本：2026-10-09 · 测试基线 1330 passed / 0 failed
> 修仙模拟器（Python + PySide6 桌面单机），AI 驱动动态剧情与立绘。

---

## 一、游戏概况

你是一名初入修仙界的散修，从练气一层开始，闭关苦修、游历历练、加入宗门、开创家族，历经筑基、金丹、元婴，再入化神、炼虚终局——最终在**天门试炼**中跨过最后一道天堑白日飞升，或者走火入魔、身死道消，走向 8 种截然不同的结局。飞升并非终点：**转世重修**开启新周目，前世的道侣将转世重逢。

- **世界观**：28 处地点（8 城 / 10 宗 / 10 野），各地遭遇迥异：城池市井繁华，宗门清净宜修，野外凶险莫测。
- **核心循环**：闭关涨修为 → 突破境界 → 渡劫（雷劫 + 心魔）→ 游历历练 → 再突破 → **天门试炼** → 飞升 → 轮回再启。
- **AI 加持**：游历遭遇由大模型动态撰写专属剧情（还会自然提及你与故人的共同往事）；主角立绘可由 AI 生成或亲手拼装。

## 二、快速上手

1. **启动**：运行 `python main.py`，登录页可直接点「继续上次」回到最近进度。
2. **创建角色**：输入道号、选性别 → 可点「捏脸…」定制形象 → 灵根觉醒 → 选择流派（法/体/剑/邪/丹/器/兽/魂/阵/符）→ 选难度。
3. **开局三件事**：在青云山闭关攒修为；游历赚资源；找宗门拜师。
4. **长线目标**：突破大境界需渡劫；炼虚圆满后冲击天门；寿元有限，飞升前先想清楚身后事——飞升之后的轮回，才是这段修仙路的真正下半场。

## 三、系统详解

### 存档管理（登录页 → 选择存档）

- 多槽位自动保存（重要事件后自动触发），列表按时间倒序，右侧显示详情（境界/地点/灵石/时长/结局/主线）。
- **继续上次**：一键载入最近存档。
- **安全性**：原子写入（断电不损档）+ 滚动备份（`saves/backups/` 保留 5 份）+ 版本迁移（旧档自动升级）。
- **导出 / 导入**：生成 zip 分享包（含自定义立绘），可备份或分享给其他玩家；导入自动落新槽位并修复立绘路径。

### 捏脸系统（双路线）

- **入口**：角色创建时点「捏脸…」；或游戏中头像右键 →「捏脸…」。
- **AI 立绘**：选 5 维特征（脸型/眼神/气质/发型/服饰）→ Agnes 生成整张水墨立绘（约 1 分钟，服务繁忙自动重试）。
- **拼装捏脸**：25 个水墨部件 × 3 肤色逐层搭配，实时预览、参数可复现；🎲 随机一键出脸。
- 采用确认制：生成后满意再采用，不会覆盖现有形象。
- 捏过脸的角色突破大境界时**不会被系统自动换头像**。

### AI 功能

- **动态事件 / 剧情增强**：游历事件的文案按地点、心境实时改写；AI 增强版稍后以「✨ AI 剧情」追加到日志，等待期间可继续游玩。
- **剧情带往事**：AI 剧情会自然提及你与道侣、故人的共同经历（结缘、双修、论道都会被"记住"）。
- **服务诊断**：设置 →「测试 AI 连接」一键自查 key / 网络 / 图模型可用性。
- **降级链**：AI 不可用时自动回退离线文案与占位图，游戏永不因 AI 中断。
- **API key**：配置于 `config/ai_config.json`（或环境变量 `AGNES_API_KEY`），已被 gitignore 保护，不会误提交。

### NPC 记忆与主动事件

- **共同回忆**：结道侣、双修、论道、收徒、传艺都会写入 NPC 的记忆；打开对话窗可在「共同回忆」区回看时间线。
- **主动事件**：NPC 会主动找你——亲密度高的道侣定期**赠丹**、弟子定期**聆教**、结怨的宿敌可能**寻衅**（小额伤害，不致死）。
- **恩怨有价**：宿敌寻衅的频率与恩怨等级挂钩，化解旧怨一劳永逸。

### 天门试炼（终局挑战）

炼虚圆满攒满修为后点突破，即进入三阶段天门试炼：

1. **问心**：心魔 ≥ 80 直接走火入魔（结局红线）；50+ 则道基不稳、天门一跃减益。
2. **渡雷**：天道注视 ≥ 90 直接天道降罚（结局红线）。平时少结怨、多行善可压注视。
3. **天门一跃**：概率判定——基础 50%，心魔/天道注视拖累，**道心 80+ 加 10%**，**飞升丹加 30%**（丹道可炼：麒麟角+灵韵草+上品妖核）。每次尝试燃烧一半灵石。
4. **失败不坏结局**：兵解重创（修为 -70%、寿元 -30、天道注视 +10），重整旗鼓可再战。

备战建议：压心魔（红尘历练）、修道心（心境 ≥ 80）、炼飞升丹、囤灵石——准备充分时成功率可达 81%，期望 1~2 次即可飞升。

### 轮回多周目（飞升之后）

达成任意结局后选「转世重修」：

- **继承选择**：按前世成就获得继承点（境界分 + 名望分 + 业力修正），自由兑换灵根保留（带衰减）、天赋、属性、携带物品、关系保留、业力洗涤；也可「放下执念，空手转世」。
- **前世羁绊**：前世道侣（或挚友）转世为重逢 NPC——初见触发重逢演出，前世情分化为好感加成；修行年谱（帮助菜单）完整保留每一世的记录。
- **跨世延续**：业力、遗物链、转世次数跨世继承；恩怨、社交、成就随新世重新积累。
- 二周目可与转世道侣**再结缘**——前世与今生的记忆在同一个人身上延续。

### 多周目模式（新游戏开局选择）

创建角色时可选五种"活法"，每种有自己的开局效应与专属遭遇（转世后延续此道）：

| 模式 | 解锁 | 核心差异 |
|---|---|---|
| **正统求道** | 无 | 标准开局，最纯粹的修仙之路 |
| **夺舍重生** | 转世 ≥ 1 次 | 保留前世一道天赋（+10%），随身灵石，但**业障 -20** |
| **天道轮回** | 已通关一次 | 悟性 +15%，**敌人强度 +20%**——恩赐与诅咒并存 |
| **凡人挑战** | 无 | **天生无灵根**，仅可选体修/符修；生命上限 +30 |
| **魔道独行** | 无 | 正道宗门皆敌（敌对关系）；攻击 +5，但**业障 -30** 起步 |

- 每种非正统模式都有**专属开场演出**（人生开篇）与**专属遭遇**：魔道会被正道围剿、遇魔道交易；凡人有"凡人之志"的体悟；轮回者窥见宿慧、承受天道常视；夺舍者忍受躯壳排异、被故主寻亲。
- 模式选择影响整局体验而非单纯数值——**转世也不会更换此道**（此道既择，一世相随）；结局画面会标注"以「魔道独行」之道，走完此生"。

### NPC 个人支线与主动事件

- 每位 NPC 都有**一条专属委托**（对话 → 社交页签「TA 的委托」）：寻物（找材料）/ 护法（替 TA 挡住妖邪）/ 复仇（替 TA 出气）三型。
- 战斗型委托接取即可**出发**：胜利得灵石 120 + 好感 15；**失败不罚，委托保留**，养好伤再来。
- 好感低于 -10 的人不会向你托付私事（魔道玩家与正道修士之间尤其如此）。
- 此外，道侣/师徒/挚友/仇敌会在月度结算时主动找上门（赠礼/聆教/寻衅等 6 类），共同经历会沉淀为“共同回忆”，AI 剧情会引用它们。

### 试炼塔（中期主动挑战）

- 入口：左侧行动面板「🗼 试炼塔」。一层一敌，共 15 层，敌人越来越强。
- 每层胜利可**三选一补给**（疗伤丹/聚气丹/灵石/灵草）；**主动撤退全额结算，战败折半**——见好就收还是搏一搏，你自己决定。
- 最高层纪录**跨世保留**，在修行图鉴里查看。

### 修行图鉴（跨世收集）

- 入口：帮助菜单 →「修行图鉴」。三个页签：**结局图鉴**（8 个，达成的紫底高亮）、**人物图鉴**（101 位 NPC，见过的亮起）、试炼塔纪录。
- 全部**跨世累计**——转世不丢，越玩越厚。

### 节日灯会（限时）

- 入口：行动面板「🏮 灯会」。节日期间开放，随机 3 道灯谜，答对 ×30 灵石，全对心境 +5；非节日期间提示“今夜无灯，灯会未开”。

### 战斗意图预告

- 战斗每回合开始时，日志会显示敌人本回合意图（如“【敌意】妖兽将施展【裂骨击】（预计伤害约 24）”）。
- 看到敌人要放大招？这回合就防御或上盾——战斗从“拼血量”变成“读招式”。

### 功能开关（设置 → 功能开关）
15 个模块自助开关（家族、领地、心魔劫、天道惩罚、寿元轮回、AI 剧情……）：
游戏内切换立即生效并自动保存；关闭 AI 类开关可减少联网与等待。

### 立绘与头像

- 大境界突破自动切换高阶立绘（未捏脸时）；捏过脸的角色保留自定义形象。
- 立绘边框随境界变色（化神霞光橙 / 炼虚虚空蓝）、突破后 12 个月内带金色光效。

## 四、常见问题

见游戏内 菜单栏 → 帮助 → 玩法指南 的「常见问题」页（AI 没反应、生图失败、头像不换、分享角色、存档安全）。

**天门试炼失败了怎么办？** 兵解重创不是结局——修为折损七成可以重攒，寿元折损 30 年可控，天门永远为你重开。
**转世后我丢了什么、留了什么？** 留下：业力、遗物链、修行年谱、前世羁绊（转世重逢）；重新积累：境界、修为、道侣、恩怨、成就。

## 五、给协作者的技术速览

- 架构：PySide6 UI 层 + `GameEngine` 门面 + 52 个 Manager + 82 个 JSON 配置（配置驱动：新功能 = JSON + 判定器 + 钩子）。
- 存档：`SaveManager` 多槽位，`SAVE_VERSION` + `_migrate` 迁移。
- 测试：`pytest tests/`（1330 用例，约 2 分钟；含轮回全链路集成测试与转世状态语义矩阵）；`tests/conftest.py` 已隔离外部 AI 调用与沙箱删除限制。
- 工具：`tools/curve_check.py`（修为曲线实测，`--pills` 带丹口径）、`tools/roam_check.py`（游历流对照）、`tools/bench_tick.py`（性能基准）、`tools/gen_face_parts.py`（捏脸部件生成）。
