# 修仙模拟器操作说明书

## 一、游戏概述

本游戏为一款文字修仙模拟器，玩家扮演一名初入仙途的修士，通过修炼、战斗、社交、经营等方式逐步提升实力，最终渡劫飞升。游戏采用"菜单驱动 + 月推进"模式，所有事件以月份为时间单位推进，操作入口集中在主窗口顶部导航栏与各功能弹窗中。

---

## 二、核心属性

| 属性 | 说明 |
|------|------|
| **境界** (realm_id) | 修为层次，从炼气初期至渡劫期，共 22 级 |
| **气血** (qi) | 修炼经验，达到阈值可尝试突破境界 |
| **生命值** (health) | 战斗与行动消耗，归零时强制休息 |
| **灵石** (spirit_stone) | 通用货币，用于购买道具、建造、交易 |
| **悟道点** (enlightenment_points) | 高境界获得，用于领悟神通 |
| **道心值** (mental_state) | 0~100，影响心境等级与心魔触发概率 |
| **心魔值** (heart_demon) | 0~100，超过阈值触发心魔劫 |

### 3.2 突破方式

突破需要满足以下全部条件：
1. **气血**达到该境界的 `breakthrough_qi_required`
2. **境界**未达到当前上限
3. **心境**满足要求（部分高阶境界需要特定道心等级）
4. 消耗 `breakthrough_cost` 灵石

突破有失败概率，失败后气血扣减，心境可能下降。

## 四、修炼系统

### 4.1 修仙流派（Cultivation Path）

玩家选择一个修仙流派，不同流派影响修炼速度、加成加成与技能获得。

| 流派 ID | 名称 | 核心特性 |
|--------|------|----------|
| `sword` | 剑宗 | 攻击加成高，剑意积累快 |
| `demon` | 魔道 | 杀戮收益高，心境下降快 |
| `zhengdao` | 正道 | 道心稳定，被动防御高 |
| `alchemy` | 丹宗 | 炼丹成功率加成 |
| `artifact` | 器宗 | 炼器品质加成 |
| `array` | 阵道 | 阵法效果增强 |

**选择时机**：在创建角色或第一次修炼前选择，选定后不可更改。

### 4.2 灵根

灵根决定修炼速度与属性加成，从 `config/spiritual_roots.json` 加载。常见类型：
- `heavenly`：天灵根，修炼速度最快
- `earthly`：地灵根，修炼速度中等
- `mortal`：凡灵根，修炼速度较慢

### 4.3 修炼操作

1. 点击主窗口「修炼」按钮
2. 选择修炼方式：
   - **打坐**：恢复气血，消耗灵石
   - **闭关**：在洞府/宗门秘境中加速修炼
   - **参悟**：消耗时间领悟技能

## 五、战斗系统

### 5.1 战斗类型

| 类型 | 触发方式 | 说明 |
|------|----------|------|
| **野外战斗** | 地点探索事件 | 随机遭遇敌人 |
| **宗门战** | 宗门弹窗 → 战争标签 | 与敌对宗门争夺灵脉 |
| **世界 BOSS** | 宗门弹窗 → 世界 BOSS 标签 | 挑战上古神兽/血魔尊者 |
| **擂台挑战** | 擂台系统 | 与其他修士 PK |
| **领地守卫** | 领地系统月度结算 | 抵御妖兽袭扰 |

### 5.2 战斗结果结算

战斗胜利后获得：
- **修为**（qi）
- **灵石**
- **物品掉落**（从敌人配置中随机掉落）

战斗失败后：
- 扣除生命值
- 可能被俘或被迫逃跑
- 继续在同一地点探索时仍可再次挑战

### 5.3 世界 BOSS 挑战条件

- 境界须达到 `min_realm_order` 要求
- BOSS 活跃时才可挑战（击败后进入重生冷却）
- 击败后获得固定参与奖励 + 掉落奖励

## 六、宗门系统

### 6.1 加入宗门

1. 点击主窗口「宗门」按钮
2. 选择「加入宗门」，查看宗门列表
3. 选择目标宗门并提交申请（需消耗贡献或灵石）

### 6.2 宗门职位

| 职位 | 解锁功能 |
|------|----------|
| `outer` | 外门弟子，基础修炼 |
| `inner` | 内门弟子，可参与宗门战、外交任务 |
| `elder` | 长老，可管理领地、发动战争 |
| `leader` | 宗主，可签订结盟、分配资源 |

### 6.3 贡献与声望

- **贡献**：通过战斗、任务、宗门活动获得，用于晋升职位
- **声望**：影响NPC态度与世界事件触发
- **忠诚度**：影响宗门战成功率加成

### 6.4 宗门战

- 内门弟子以上可发起
- 胜率 = 基础胜率 + 贡献加成 + 宗门战参与加成 + 同盟加成 - 对方难度
- 胜利：获得贡献、声望，夺取灵脉控制权
- 失败：损失健康、忠诚度下降，关系恶化

### 6.5 灵脉争夺

灵脉是宗门间的战略资源，控制灵脉可提升洞府修炼加成。灵脉按地点分布，战败方失去控制权，胜方获得。

## 七、外交系统

### 7.1 宗门关系

| 关系值范围 | 状态 |
|-----------|------|
| -100 ~ -51 | 死敌 |
| -50 ~ -1 | 敌对 |
| 0 | 中立 |
| 1 ~ 49 | 友好 |
| 50 ~ 100 | 至交 |

### 7.2 外交任务

点击宗门弹窗 →「外交」标签，可接取外交任务：

| 任务 ID | 名称 | 目标关系 | 职位 | 消耗 |
|--------|------|----------|------|------|
| `gift_to_friend` | 结交友好宗门 | 友好 | 内门 | 300 贡献 |
| `sabotage_enemy` | 破坏敌对宗门 | 敌对 | 内门 | 400 贡献 |
| `mediate_neutral` | 游说中立宗门 | 中立 | 外门 | 200 贡献 |

任务成功：提升/降低目标宗门关系，获得贡献与忠诚度奖励。
任务失败：关系变化幅度缩小，无额外奖励。

### 7.3 结盟

- 与友好宗门（关系 ≥ 50）可签订同盟
- 消耗 5000 贡献
- 同盟有效期 30 个月，到期自动解除
- 同盟期间：商店折扣 +10%，宗门战胜率 +10%
- 可单方面解除同盟（关系归零）

## 八、洞府系统

### 8.1 洞府类型

| 类型 | 解锁条件 | 说明 |
|------|----------|------|
| **租借洞府** | 初始可用 | 花费灵石短期租用 |
| **私人洞府** | 拥有后解锁 | 永久建筑，可升级 |
| **野外洞府** | 探索发现 | 占领野生洞府 |

### 8.2 洞府设施

- **修炼室**：修炼速度加成
- **药园**：种植灵草，产出炼丹材料
- **炼丹房**：炼制丹药
- **炼器房**：锻造法器
- **闭关室**：快速恢复状态

### 8.3 洞府占领

野外存在可占领洞府，占领后需消耗灵石与时间建设，成功后成为永久私人洞府。占领时需通过战斗击退原主人。

## 九、家族系统

### 9.1 创建家族

- 境界 ≥ 金丹初期（order 14）
- 消耗 5000 灵石 + 200 声望
- 可自定义家族名、家训、阵营

### 9.2 家族成员

成员类型：
- **后裔**：自动繁衍产生
- **收徒**：手动收徒，成为家族成员
- **联姻**：与其他家族联姻获得配偶

成员任务分配：
- `cultivate`：修炼
- `manage`：经营家族资源
- `explore`：外出探索
- `diplomacy`：外交活动

### 9.3 家族月度结算

每月自动结算家族产出（灵石、修为、声望），同时触发随机家族事件。

## 十、社交系统

### 10.1 NPC 交互

在地点中可遇到 NPC，进行以下交互：
- **论道**：与 NPC 讨论道法，获得悟道点或心境变化
- **双修**：与道侣双修，提升双方修为（需道侣关系）
- **收徒**：收 NPC 为徒弟，徒弟可继承家族
- **恩怨**：建立或解除恩怨关系，影响后续战斗与任务

### 10.2 恩怨系统

- 每个 NPC 与玩家有独立恩怨值（-100 ~ 100）
- 击杀/帮助 NPC 会改变恩怨
- 恩怨过深时 NPC 可能派杀手报复
- 恩怨过深时无法与该 NPC 的宗门结盟

### 10.3 伴侣系统

- 可通过特定事件或 NPC 互动结识伴侣
- 伴侣提供被动加成（修炼速度、战斗能力等）
- 可生育后裔，后裔继承部分属性
- 伴侣死亡会导致道心大幅下降

## 十二、炼丹与炼器

### 12.1 炼丹

- 需要「炼丹房」建筑
- 消耗灵草 + 灵石，产出丹药
- 丹药品级：凡丹 → 灵丹 → 仙丹
- 品质影响丹药效果（修为加成、治疗效果等）

### 12.2 炼器

- 需要「炼器房」建筑
- 消耗矿石 + 灵石，产出法器
- 法器品级：凡器 → 灵器 → 神器
- 品质影响攻击力、防御力等属性

### 12.3 品质判定

品质由以下因素决定：
- 玩家炼丹/炼器技能等级
- 建筑等级加成
- 灵草/矿石品质
- 随机幸运判定

## 十四、心境与道心

### 14.1 道心值

道心值（0~100）反映修士的精神状态：
- 高道心：提升悟道成功率，降低心魔触发概率
- 低道心：修炼速度下降，易生心魔

### 14.2 心魔

当心魔值超过阈值时触发心魔劫，进入幻境挑战。心魔劫可通过以下行为积累：
- 杀戮（尤其正道修士）
- 道侣陨落
- 重大挫折

### 14.3 心境特质

达到一定道心后，可领悟心境特质，提供被动加成。特质包括：
- 坚韧：提升生命值
- 冷静：提升战斗闪避
- 顿悟：提升悟道点获取
- 无畏：提升战斗伤害

## 十五、渡劫飞升

### 15.1 渡劫条件

- 境界达到渡劫期（`tribulation_early`）
- 道心值达到要求
- 完成所有前置任务与试炼

### 15.2 渡劫流程

1. 选择渡劫时间（需在灵气充沛的地点）
2. 触发渡劫事件，进入战斗（天劫）
3. 渡劫成功：飞升仙界，游戏胜利
4. 渡劫失败：境界跌落，道心重置，进入轮回

### 15.3 轮回系统

渡劫失败后可选择轮回：
- 保留部分悟道点
- 保留部分心境特质
- 以新身份重新开局

## 十六、世界事件

### 16.1 事件类型

世界事件是全局性宏观事件，影响所有玩家：
- **灵气潮汐**：提升全服修炼速度
- **魔道入侵**：增加敌对NPC数量
- **兽潮**：妖兽大规模迁徙，提升野外危险度
- **天灾**：地点环境恶化，探索风险增加

### 16.2 事件生命周期

1. **触发**：满足条件后随机或定时触发
2. **持续**：持续指定月份，期间持续生效
3. **结束**：到期后恢复，部分事件有冷却期

## 十九、常见问题

**Q：如何提升境界？**
A：通过修炼（打坐/闭关）积累气血，气血达到阈值后点击突破按钮。

**Q：如何加入宗门？**
A：点击「宗门」按钮 → 选择「加入宗门」→ 选择目标宗门并提交申请。

**Q：世界 BOSS 无法挑战？**
A：检查境界是否达到 BOSS 的 `min_realm_order` 要求，且 BOSS 当前处于活跃状态。

**Q：宗门战胜率如何提高？**
A：提升境界、增加宗门贡献、提升宗门战参与次数、签订结盟、控制更多灵脉。

**Q：如何解除外交任务？**
A：点击「宗门」→「外交」标签 → 选择当前任务 → 点击「取消任务」。

**Q：道心值过低怎么办？**
A：避免杀戮行为，进行论道、参悟等提升道心的活动，或购买恢复道具。

## 二十、游戏目标

1. **短期目标**：提升境界，掌握战斗与修炼技能
2. **中期目标**：加入或创建宗门/家族，建立势力
3. **长期目标**：渡劫飞升，成就仙人之位

游戏支持多周目轮回，每次轮回保留部分悟道点与心境特质，逐渐变强。
