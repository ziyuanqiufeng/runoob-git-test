# 《问道长生》修仙模拟器

PySide6 桌面单机修仙模拟游戏：从练气散修到元婴飞升，AI 驱动动态剧情与专属立绘。

![测试基线](https://img.shields.io/badge/pytest-1327_passed-brightgreen)

## 特性

- **深度养成**：22 级境界（练气→炼虚圆满）、五行+变异/融合灵根、十大流派、渡劫心魔、天门试炼三阶段飞升终局
- **开放世界**：28 处地点（8 城 / 10 宗 / 10 野）差异化事件权重，61 个随机事件（终局境界门槛 + 周目模式专属双维度过滤）
- **新玩法**：试炼塔（15 层波次挑战 + 三选一补给）、战斗意图预告、修行图鉴（结局/人物跨世收集）、节日灯会（灯谜）
- **AI 动态剧情**：Agnes LLM 按地点、心境生成专属剧情（异步不卡界面，离线自动降级），NPC 记忆注入——剧情里带着你与故人的共同往事
- **AI 角色引擎**：NPC 拥有共同经历记忆（对话窗可回看）、主动事件（道侣赠丹/弟子聆教/宿敌寻衅）、转世重逢
- **轮回多周目**：结局后转世重修，继承点兑换天赋/灵根/遗物链；前世道侣转世重逢，宿慧叙事延续跨世情缘
- **捏脸系统**：AI 提示词捏脸（5 维特征生成整张立绘）+ 拼装捏脸（25 个水墨部件实时合成）双路线
- **玩法矩阵**：宗门 / 家族 / 领地 / 坊市 / 拍卖 / 竞技场 / 世界 BOSS / 藏宝图 / 红尘羁绊 / 百家争鸣 / 8 结局
- **工程保障**：1327 个自动化测试（含轮回全链路集成测试）、存档原子写入 + 滚动备份 + 版本迁移 + 导出导入、AI 服务一键诊断

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

### Windows 绿色启动（临时文件不落 C 盘）

项目根目录已提供三个批处理脚本，会把临时文件、pip 缓存重定向到项目内的
`.tmp/` 与 `.cache/`：

- `install_deps.bat`：创建 `.venv`（如缺失）并安装依赖
- `run_game.bat`：双击启动游戏
- `run_tests.bat`：运行全量测试；也可传测试路径，如 `run_tests.bat tests/test_infrastructure.py`

## 运行测试

```bash
python -m pytest tests/ -q          # 全量回归（约 100 秒）
```

## 目录结构

```
main.py            # 入口：登录 → 角色创建 → 主窗口
game/              # 引擎层：GameEngine 门面（1633 行）+ 12 个域 Mixin + 52 个 Manager
ui/                # 界面层：主窗口 + 75 个对话框/面板（PySide6）
config/            # 配置层：82 个 JSON（境界/事件/物品/功能开关/捏脸…）
tests/             # 测试层：129 文件，1327 用例
tools/             # 工具：捏脸部件生成、操作手册生成
docs/              # 设计文档与玩家手册
```
