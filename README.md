# 《问道长生》修仙模拟器

PySide6 桌面单机修仙模拟游戏：从练气散修到元婴飞升，AI 驱动动态剧情与专属立绘。

![测试基线](https://img.shields.io/badge/pytest-1197_passed-brightgreen)

## 特性

- **深度养成**：18 级境界、五行+变异/融合灵根、十大流派、渡劫心魔、寿元轮回
- **开放世界**：28 处地点（8 城 / 10 宗 / 10 野）差异化事件权重，35+ 随机事件（含去重窗口）
- **AI 动态剧情**：Agnes LLM 按地点、心境生成专属剧情（异步不卡界面，离线自动降级）
- **捏脸系统**：AI 提示词捏脸（5 维特征生成整张立绘）+ 拼装捏脸（25 个水墨部件实时合成）双路线
- **玩法矩阵**：宗门 / 家族 / 领地 / 坊市 / 拍卖 / 竞技场 / 世界 BOSS / 藏宝图 / 红尘羁绊 / 百家争鸣 / 8 结局
- **工程保障**：1197 个自动化测试、存档原子写入 + 滚动备份 + 版本迁移 + 导出导入、AI 服务一键诊断

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

## 运行测试

```bash
python -m pytest tests/ -q          # 全量回归（约 100 秒）
```

## 目录结构

```
main.py            # 入口：登录 → 角色创建 → 主窗口
game/              # 引擎层：GameEngine 门面（1633 行）+ 12 个域 Mixin + 52 个 Manager
ui/                # 界面层：主窗口 + 75 个对话框/面板（PySide6）
config/            # 配置层：61 个 JSON（境界/事件/物品/功能开关/捏脸…）
tests/             # 测试层：118 文件，1197 用例
tools/             # 工具：捏脸部件生成、操作手册生成
docs/              # 设计文档与玩家手册
```
